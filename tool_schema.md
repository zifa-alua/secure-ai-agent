# Схемы инструментов агента

Агент сам выбирает нужный инструмент через function calling (tool use) модели
Claude — без ручных `if/else` по ключевым словам.

---

## 1. `calculator`

- **Назначение:** арифметические вычисления.
- **Вход:** `{ "expression": string }` — выражение с `+ - * /` и скобками.
- **Пример:** `{ "expression": "(2+3)*4" }` → `20`
- **Ограничения / безопасность:**
  - белый список символов: только цифры и `+ - * / ( ) .`;
  - собственный парсер, **без `eval`/`ScriptEngine`** — произвольный код выполнить нельзя;
  - максимум 200 символов.

---

## 2. `sql_query` (серьёзный инструмент)

- **Назначение:** read-only чтение из локальной SQLite-базы.
- **Вход:** `{ "query": string }` — один `SELECT`.
- **Схема БД:**
  - `products(id, name, category, price)`
  - `customers(id, name, city)`
- **Пример:** `{ "query": "SELECT name, price FROM products WHERE category='Мебель'" }`
- **Ограничения / безопасность:**
  - разрешён **только `SELECT`**;
  - **read-only соединение** (драйвер физически запрещает запись);
  - запрет операций: `INSERT / UPDATE / DELETE / DROP / ALTER / CREATE / PRAGMA / ATTACH` и др.;
  - запрет нескольких стейтментов (нет `;` внутри);
  - вывод ограничен 100 строками;
  - база содержит только тестовые данные (никаких секретов).

---

## 3. `current_datetime`

- **Назначение:** текущая дата и время сервера.
- **Вход:** нет параметров.
- **Пример ответа:** `2026-09-29 15:00:00`
- **Ограничения / безопасность:** только чтение времени, побочных эффектов нет.
