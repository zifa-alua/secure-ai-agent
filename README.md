# Secure AI Agent

Простой AI-агент на Java, который принимает запрос в консоли (CLI), обращается к
модели **Claude** (через OpenRouter) и умеет вызывать инструмент — **калькулятор**.
Проект сделан с упором на базовую культуру безопасности.


## Архитектура (в 4 предложениях)

Пользователь вводит запрос в CLI (`Main`), запрос уходит в `LlmClient`, который
обращается к модели Claude через OpenRouter. Если модель решает, что нужен расчёт,
она возвращает **tool call**, и `LlmClient` выполняет безопасный `Calculator`, а
результат отправляет обратно модели для формирования финального ответа. Каждый
запрос и ответ записывается в файл `logs/agent.log` через `Logger` — **без
секретов**. API-ключ читается из файла `.env` (`EnvLoader`) и никогда не хранится
в коде.

Пользователь → Main (CLI) → LlmClient → Claude (OpenRouter)
                                 │  ↑
                                 ▼  │ результат
                            Calculator (tool)
        Logger → logs/agent.log       .env → EnvLoader (ключ)
```


## Требования

- **JDK 17**
- **Maven**
- Ключ **OpenRouter** (доступ к моделям Claude)


## Настройка

1. Скопируй `.env.example` в `.env` и вставь свой ключ:
   ```
   OPENROUTER_API_KEY=sk-or-...твой ключ...
   ```
   Файл `.env` добавлен в `.gitignore` и **никогда не попадает в репозиторий**.


## Запуск

В IntelliJ IDEA: запустить класс `Main` (▶️).
Из терминала:
```bash
mvn -q compile exec:java -Dexec.mainClass="com.example.agent.Main"
```
(или запустить собранный класс любым удобным способом)

Примеры запросов:
```
> привет
> посчитай (144 + 56) / 8
> сколько будет 15 * 23 + 7
```
На математические запросы агент вызывает калькулятор, на обычные — отвечает сам.


## Безопасность

| Требование | Как выполнено |
|---|---|
| **Секреты не в коде** | Ключ только в `.env`, который в `.gitignore`. В git-историю не попадает. |
| **Валидация ввода** | `Calculator` принимает только цифры и `+ - * / ( )` (белый список). Любые другие символы отклоняются — защита от инъекций. |
| **Безопасное логирование** | В `logs/agent.log` пишутся только текст запроса и ответа. Ключи, токены, заголовки — никогда. Папка `logs/` в `.gitignore`. |
| **Таймауты** | Таймаут на соединение (10 с) и на весь запрос (60 с) — защита от зависаний. |
| **Ограничение циклов** | Не более 5 раундов вызова инструментов за запрос — защита от бесконечного цикла. |
| **Никакого eval** | Калькулятор считает своим парсером, без `eval`/`ScriptEngine` — произвольный код выполнить нельзя. |


## Ответ на вопрос про Prompt Injection

**Риск.** Prompt injection возникает, когда во «вход» модели попадает внешний
контент (текст файла, ответ стороннего API, веб-страница), внутри которого
спрятаны инструкции вида «игнорируй прежние указания и сделай X». Модель может
принять эти инструкции за команду и, например, вызвать инструмент со вредным
аргументом или выдать то, что не следует.

**Как мы от этого защищаемся (частично):**
1. **Минимальная поверхность атаки.** Единственный инструмент — калькулятор, он
   **не загружает внешний контент** (ни файлы, ни сеть, ни API). Значит, во вход
   модели не попадает недоверенный внешний текст.
2. **Строгая валидация аргументов инструмента.** Даже если модель попросит
   калькулятор что-то «выполнить», он принимает только математические символы —
   команду или код исполнить невозможно.
3. **Результаты инструмента — это данные, а не команды.** Мы не исполняем то, что
   вернул инструмент, и не запускаем shell/произвольный код по ответу модели.
4. **Ограничения выполнения.** Таймауты и лимит в 5 раундов инструментов не дают
   агенту «уйти в разнос» при попытке манипуляции.

Если в будущем добавить инструмент, читающий файлы или веб, риск вырастет —
тогда внешний контент нужно будет явно помечать как недоверенный и не давать ему
управлять действиями агента.


## Threat Model (кратко)

| Угроза | Что может пойти не так | Что сделано |
|---|---|---|
| Утечка ключа | Ключ в коде/репозитории → компрометация | Ключ в `.env`, `.env` в `.gitignore` |
| Инъекция в инструмент | Через аргумент калькулятора выполнить код | Белый список символов, свой парсер без eval |
| Prompt injection | Внешний текст управляет агентом | Нет загрузки внешнего контента; результаты — данные |
| Утечка данных в логах | В лог попадают ключи/приватное | Логируем только запрос/ответ, без секретов |
| Зависание / DoS | Внешний API не отвечает | Таймауты + лимит раундов инструментов |
