# Secure AI Agent — мульти-инструментальный агент

AI-агент на Java, который принимает запрос (через CLI или HTTP), обращается к
модели **Claude** (через OpenRouter) и **сам выбирает** нужный инструмент из
нескольких через function calling. Сделан с упором на безопасность.

Задание №2 — продолжение Задания №1: добавлены новые инструменты, память
диалога, структурированное логирование и защищённый HTTP-эндпоинт.

---

## Инструменты (агент выбирает сам)

| Инструмент | Что делает |
|---|---|
| `calculator` | арифметические вычисления |
| `sql_query` | read-only SELECT к локальной SQLite-базе (products, customers) |
| `current_datetime` | текущая дата и время |

Модель сама решает, какой инструмент вызвать (через tool use API Claude), без
ручных `if/else`. Подробные схемы — в [`tool_schema.md`](tool_schema.md).

---

## Архитектура

Запрос приходит из CLI (`Main`) или по HTTP (`ApiServer`), попадает в `LlmClient`,
который обращается к Claude через OpenRouter. Если модель решает использовать
инструмент, она возвращает **tool call**, и `LlmClient` вызывает нужный класс
(`Calculator` / `SqlTool` / дата-время), а результат отправляет обратно модели.
Каждый вызов инструмента логируется структурированно (`Logger` → JSON), считается
в `Stats`. Память диалога (последние N реплик) хранится в `LlmClient`. Ключи
читаются из `.env` (`EnvLoader`) и никогда не хранятся в коде.

## Настройка

Скопируй `.env.example` в `.env` и заполни:
```
OPENROUTER_API_KEY=sk-or-...      # ключ OpenRouter (модель Claude)
AGENT_API_KEY=придумай-секрет      # пароль к HTTP-эндпоинту
```
`.env` в `.gitignore` — в репозиторий не попадает.

## Запуск

В IntelliJ: запустить класс `Main` (▶️). Работают одновременно CLI и HTTP-эндпоинт.

### CLI
```
> посчитай 15 * 23 + 7
> какие товары в категории Мебель?
> какое сегодня число?
```
Агент помнит контекст сессии — можно задавать уточняющие вопросы.

### HTTP-эндпоинт (с аутентификацией)
```
POST http://localhost:8080/chat
X-API-Key: <твой AGENT_API_KEY>
Content-Type: application/json

{ "message": "какие товары в категории Мебель?" }
```
- Без заголовка `X-API-Key` или с неверным ключом → **401** (до обращения к LLM).
- `GET /stats` (с ключом) → счётчики вызовов инструментов.

## Безопасность

| Требование | Как выполнено |
|---|---|
| Секреты не в коде | Ключи только в `.env` (в `.gitignore`) |
| Валидация ввода | Калькулятор — белый список символов; без `eval` |
| Безопасный доступ к БД | Только `SELECT`, read-only соединение, запрет DROP/DELETE/множественных стейтментов |
| Аутентификация эндпоинта | `X-API-Key`; анонимные запросы отклоняются с 401 **до** вызова LLM |
| Rate limiting | 20 запросов/мин с клиента, иначе 429 |
| Безопасное логирование | В лог пишутся запрос/ответ и метаданные инструмента; ключей нет; `logs/` в `.gitignore` |
| Таймауты | Таймаут соединения (10 с) и запроса (60 с) |
| Ограничение циклов | Не более 5 раундов инструментов за запрос |

## Структурированное логирование

`logs/agent.log` — JSON-строки. Пример:
```json
{"ts":"2026-09-29 15:00:01","type":"user","text":"какие товары в категории Мебель?"}
{"ts":"2026-09-29 15:00:03","type":"tool","tool":"sql_query","input":"{\"query\":\"SELECT ...\"}","duration_ms":9,"status":"ok"}
{"ts":"2026-09-29 15:00:04","type":"agent","text":"В категории Мебель: Стол, Стул"}
```
Видно: какой инструмент вызван, усечённый вход, время выполнения, успех/ошибка.

## Ответ на вопрос про Prompt Injection

**Риск.** Prompt injection возникает, когда во вход модели попадает внешний
контент (текст файла, ответ API, веб-страница) со спрятанными инструкциями вида
«игнорируй прежние указания и сделай X». Модель может принять их за команду.

**Как защищаемся (частично):**
1. Инструменты **не загружают недоверенный внешний контент**: калькулятор считает
   математику, `sql_query` читает только локальную тестовую базу, дата-время не
   принимает ввод.
2. **Строгая валидация аргументов** каждого инструмента (белый список символов,
   только SELECT) — вредную «команду» исполнить нельзя.
3. **Результаты инструментов — данные, а не команды**: мы не исполняем то, что
   они вернули, и не запускаем shell/произвольный код.
4. **Ограничения выполнения**: таймауты, лимит раундов инструментов, rate limit.

## Threat Model (кратко)

| Уровень | Угроза | Что сделано |
|---|---|---|
| КРИТ | Инъекция в инструмент (код/SQL) | Белый список; только SELECT; read-only; без eval |
| КРИТ | Утечка ключей | Ключи в `.env`, `.env` в `.gitignore` |
| ВЫСОКИЙ | Анонимный доступ к эндпоинту | Обязательный `X-API-Key`, иначе 401 |
| ВЫСОКИЙ | DoS / перерасход API | Rate limiting (429) + таймауты |
| СРЕДНИЙ | Prompt injection | Нет загрузки внешнего контента; результаты — данные |
| СРЕДНИЙ | Утечка данных в логах | Логируем только запрос/ответ, без секретов |
