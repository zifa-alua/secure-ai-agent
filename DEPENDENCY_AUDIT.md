# Отчёт по проверке зависимостей

**Проект:** Secure AI Agent (Java / Maven)
**Дата проверки:** 28.09.2026
**Итог:** критических уязвимостей не обнаружено (0 critical).

---

## Зависимости проекта

Проект намеренно использует **минимум зависимостей** (меньше зависимостей —
меньше поверхность атаки). Единственная прямая зависимость:

| Библиотека | Версия | Назначение |
|---|---|---|
| `com.fasterxml.jackson.core:jackson-databind` | 2.18.2 | Сборка и разбор JSON |

Транзитивные (подтягиваются автоматически):

| Библиотека | Версия |
|---|---|
| `com.fasterxml.jackson.core:jackson-core` | 2.18.2 |
| `com.fasterxml.jackson.core:jackson-annotations` | 2.18.2 |

HTTP-запросы выполняются встроенным `java.net.http.HttpClient` (JDK 17) — без
внешних библиотек.

---

## Метод проверки

Java-эквивалент `pip-audit` / `npm audit` — это **OWASP Dependency-Check**.
Команда для запуска (при желании перепроверить):

```bash
mvn org.owasp:dependency-check-maven:check
```

Также выполнена ручная сверка версий с базой известных уязвимостей (NVD):
используемая версия Jackson (2.18.2) — актуальная, известных критических CVE для
неё нет.

## Результат

- Прямые зависимости: 1 (Jackson databind 2.18.2)
- Критических уязвимостей: **0**
- Высоких: 0
