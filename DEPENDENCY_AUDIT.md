## Зависимости проекта

Проект использует минимум зависимостей (меньше зависимостей — меньше поверхность
атаки). Прямые зависимости:

| Библиотека | Версия | Назначение |
|---|---|---|
| `com.fasterxml.jackson.core:jackson-databind` | 2.18.2 | Сборка и разбор JSON |
| `org.xerial:sqlite-jdbc` | 3.47.1.0 | Локальная SQLite-база (инструмент sql_query) |

Транзитивные:

| Библиотека | Версия |
|---|---|
| `com.fasterxml.jackson.core:jackson-core` | 2.18.2 |
| `com.fasterxml.jackson.core:jackson-annotations` | 2.18.2 |

`com.sun.net.httpserver`), без внешних библиотек.

## Метод проверки

Java-эквивалент `pip-audit` / `npm audit` — **OWASP Dependency-Check**:

```bash
mvn org.owasp:dependency-check-maven:check
```

Также выполнена ручная сверка версий с базой известных уязвимостей (NVD).
Используемые версии Jackson (2.18.2) и sqlite-jdbc (3.47.1.0) — актуальные,
известных критических CVE для них нет.
